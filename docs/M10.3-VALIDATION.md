## Real Electron window

源码开发窗口已通过 macOS accessibility surface 检查：

1. 侧边栏显示独立“Provider 设置”和当前 Provider 状态；
2. 设置对话框同时展示 DeepSeek/OpenAI 状态卡，Provider 与 Skills/MCP/Browser 不再混在同一折叠区；
3. 已有 DeepSeek 只显示“系统安全存储”，没有回显凭据；OpenAI 显示“未配置”；
4. 选择未配置 OpenAI 后，“开始任务”保持禁用并提供配置入口；
5. Model/Base URL 位于当前 Run 高级设置；保存、验证连接与开始任务是三个独立动作。
6. Composer 控制台采用“任务输入 + 紧凑工具栏”两层结构：移除字段标题行和 16 列空栅格，Provider、凭据、信任、模式、并发、容量与扩展入口在同一工具条内占用内容所需宽度，执行按钮固定在右侧；窄窗口只让工具项自然换行。

验收没有输入、替换或删除任何真实凭据，也没有点击“验证连接”或启动真实 Run，因此没有产生模型费用或新的外部数据传输。连接动作由确定性本地夹具覆盖；真实 Provider 验证保留给知情用户显式触发。
