## 明确边界

- 当前恢复是原请求重放，不是模型 turn checkpoint resume。
- Electron single-instance lock 只约束 Desktop；独立 CLI 进程不共享 Desktop 的进程内执行容量和 lease。
- `git worktree remove --force` 会删除隔离区未提交改动，因此只允许用户通过默认取消的原生确认框触发。
- `.localbuddy/runs/*/run-request.json` 含用户目标，必须继续作为本地私有运行状态。
