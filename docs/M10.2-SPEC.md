# M10.2 · First Trusted Run

## Product decision

首次体验的目标不是让用户看完功能介绍，而是让用户在最低风险下完成第一个真实结果，并理解输入、外发、审计和人工控制边界。

指引界面可以采用会话形态，但它不是 Provider 驱动的 Agent：指引必须在没有 API Key 时可用，不调用模型、不读取工作区、不启动 Run，也不进入普通 Run 历史或成功率统计。

## Required surfaces

1. 侧边栏永久保留“指引与示例”入口；用户可以跳过、关闭和重新打开；
2. 首次打开显示本地指引会话和三个结果导向入口：教程简报、本地资料研究、安全 Coding；
3. 启动前只显示工作区/Git readiness、Provider 凭据是否可用和人工控制边界；Renderer 不能读取或回显 secret；
4. 用户明确点击后才能创建教程工作区；目录必须位于应用数据根下、使用唯一名称，并且复用时不得覆盖文件；
5. 所有模板只能填入 Composer，不能自动调用 `startRun`；
6. Running、审批、Integration、成功、失败和中断提示必须由真实 `DesktopRunView` 状态产生；
7. 没有最近工作区时保持未选择，不得默认把整个 Documents 设为工作区；
8. 切换工作区时清空旧目标，防止上下文意外进入另一目录。

## Local state and IPC

- `onboarding.json` 使用版本 `1`，只保存 `guideSeen`、`contextHelpEnabled` 和由 Main 写入的教程工作区路径；
- 文件采用原子替换，macOS/Linux 权限固定为 `0600`；损坏或未知版本 fail safe 到重新显示指引；
- Main 可读取凭据以判断可用性，但 Bootstrap 只返回 `{ deepseek: boolean, openai: boolean }`；
- Renderer 通过独立 IPC 检查工作区是否存在、是否为 Git 仓库、是否为 LocalBuddy 教程目录；检查不读取业务文件内容；
- 教程目录及文件在 macOS/Linux 分别使用 `0700` / `0600`。

## Tutorial content

教程工作区只包含 LocalBuddy 自行编写的一份完全虚构会议记录。默认模板要求生成可编辑的 `会议纪要.docx`，整理关键结论、行动项、负责人、截止时间和待确认事项；不得补写记录中不存在的数据。用户也可以明确选择一份 TXT、Markdown 或 DOCX 会议记录，运行记录仍保存在独立教程目录，原文件不修改且不把所在文件夹扩张为读取范围。

教程材料是合成输入，但用户点击开始后的 Provider/Agent/工具/Artifact 执行是真实 Run；产品必须明确区分两者。

## Explicitly out of scope

- 自由对话或生成式 Guide Agent；
- 持久多轮聊天线程；
- 预制假 Run、录制事件或模拟成功结果；
- 远程遥测、个性化推荐或首次启动自动联网；
- 自动开始任务、自动读取私人目录或预先批准外部副作用。

## Acceptance

- 没有 Provider 时仍能浏览完整指引；
- 没有工作区时 Composer 不能启动，并明确提供选择/教程入口；
- 创建教程后可见三个合成文件，重复创建不覆盖用户修改；
- 模板预填后 Run 数和事件数保持不变；
- 真实历史 Run 显示与其当前状态一致的上下文提示；
- 指引关闭后可从侧边栏恢复；
- Core/Main/Preload/Renderer TypeScript、确定性测试和真实 Electron 窗口验收通过。
