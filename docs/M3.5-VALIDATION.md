## 明确边界

- 同 Run Coding resume 当前只通过 Desktop 暴露；CLI 尚无 resume 命令。
- model-inflight 仍会从最后消息边界重新请求，可能产生额外模型费用。
- started 但未 completed 的写入/执行工具、主仓库或 worktree 漂移、patch/Artifact/Proposal 不一致会阻断自动续跑。
- checkpoint 原子 rename 不等于断电级 fsync 保证；文件系统损坏仍需要人工恢复。
- Git worktree 只隔离版本与文件副作用，不是恶意脚本的 OS 沙箱。
- checkpoint 含 Prompt、模型消息、工具输出和本地路径，必须留在被忽略的 `.localbuddy/` 私有目录。
